# Archived material

These files are retained for reference, not for standard runs. Historical scripts/configurations may contain old paths and must be reviewed before reuse. Nothing here is called by the standard new-run generator.

- configs/: full-option templates and historical run configurations.
- templates/: optional-analysis and pooled-sample sheets.
- scripts/: historical pooling and downsampling utilities.
- presentation/: extracted oral presentation material.
- reference/: older reference notes.
- legacy_docs/: retired quick starts and walkthroughs.

Use [current quick start](../quick-start.md) and [technical manual](../docs/USER_MANUAL_EN.md).
